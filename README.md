# CRM Comercial — MaqCampo

Painel do funil comercial (Grandes Contas / parceria Bauer).

**Acesso:** https://mcpoirrigacao.github.io/CRMCOMERCIAL/

- O painel abre vazio: os dados só aparecem depois de digitar a senha no menu lateral.
- Os dados ficam na planilha central do Google e são lidos/gravados pelo Apps Script.
- Nenhuma senha e nenhum dado de cliente ficam neste repositório.
